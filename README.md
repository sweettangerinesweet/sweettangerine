# 🍊 Sweet Tangerine

A cozy, modern, and mobile-friendly personal library powered by Google Sheets.

## ✨ Features

- 🔍 Instant Search
- 🏷 Genre Filter
- ↕ Sort Books
- 📚 Book Detail Sheet
- 📱 Responsive Design
- ⚡ Progressive Web App (PWA)
- ☁ Google Sheets as Database

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Google Sheets API
- GitHub Pages

## 🚀 Getting Started

Clone this repository:

```bash
git clone https://github.com/YOUR_USERNAME/sweettangerine.git
```

Open `index.html` using Live Server.
